<h1>osTicket - Ticket Lifecycle: Intake Through Resolution</h1>
This tutorial outlines the lifecycle of a ticket from intake to resolution within the open-source help desk ticketing system osTicket.<br />


<h2>Video Demonstration</h2>

- ### [YouTube: How to create, work, and resolves tickets within osTicket](https://www.youtube.com)

<h2>Environments and Technologies Used</h2>

- Microsoft Azure (Virtual Machines/Compute)
- Remote Desktop
- Internet Information Services (IIS)

<h2>Operating Systems Used </h2>

- Windows 10</b> (21H2)

<h2>Ticket Lifecycle Stages</h2>

- Intake
- Assignment and Communication
- Working the Issue
- Resolution

1. Creating a New Ticket
Navigate to the End User Site of osTicket.
Select the option to Create a New Ticket.
Fill in the User Information (name, email, etc.) and details about the Technical Issues.

![AgentLogin](https://github.com/user-attachments/assets/134b5bd1-537c-4be1-9d58-b1d9baf126e2)

![AgentAllTickets](https://github.com/user-attachments/assets/34177261-3ea6-4d1d-8842-984bd520b798)

2. Logging in as an Agent
Log in to osTicket as an Agent (Worker) using the credentials.
Navigate to the Tickets tab to view all open tickets.

![TicketEdits](https://github.com/user-attachments/assets/e4dc636e-0e0a-4a12-a167-d4a9adca90f4)

![TicketUpdateEX](https://github.com/user-attachments/assets/5bf22b57-f943-4bd4-ae98-5f5c8c59765c)

![TicketUpdateEX2](https://github.com/user-attachments/assets/4169facc-adc4-421c-8c30-6ad1d7f95ec5)

3. Viewing and Managing Ticket Details
Click on a specific ticket to see its details, such as:
Priority
SLA (Service Level Agreement)
Creation Date
Other relevant ticket information.
To assign a ticket:
Click on Unassigned next to the "Assigned To" section.
Select an Agent from the dropdown to assign the ticket.
4. Adjusting SLA
Change the SLA Plan of the ticket in the corresponding section if necessary.

![TicketThread](https://github.com/user-attachments/assets/7bca91f4-ebcd-49ff-a0ad-8e70e4fa9539)

![TicketReply](https://github.com/user-attachments/assets/ad16488c-35ad-4684-81da-a0009276c5ca)

5. Tracking Ticket Changes
Review the Thread of changes and updates made to the ticket.
At the bottom of the ticket, post Replies to communicate updates to the user.

![ClosingReply](https://github.com/user-attachments/assets/6f8710c2-114f-471e-8209-fa2908e251a7)

![ClosingResolved](https://github.com/user-attachments/assets/898590bb-72ab-4e82-9b40-6ca05244779b)

6. Simulating Issue Resolution
Simulate resolving the issue.
Post a reply as though the issue has been addressed and resolved.

![ClosedTicketView](https://github.com/user-attachments/assets/5318f75e-8ea9-4714-b198-ce4b5a792506)

7. Resolving and Closing the Ticket
Once resolved, the ticket can be viewed under Closed Tickets.


# **osTicket: Creating and Working Tickets is Now Complete!**

We've successfully gone through the life cycle of a ticket from creation to resolution. Along the way, we made necessary changes to the tickets, such as:  
- Assigning the tickets to agents.  
- Updating the SLA (**Service Level Agreement**).  
- Commenting to create a clear communication thread.  

This process ensures efficient ticket management and resolution within the osTicket system.
